# Data Structures and Algorithms (DSA) — Course Contents

## 1. Programming Foundations

- Variables, data types, and operators
- Conditional statements and loops
- Functions and parameter passing
- Basic input and output
- References, pointers, and memory basics
- Problem-solving and tracing code

## 2. Complexity Analysis

- Time and space complexity
- Big O, Big Omega (Ω), and Big Theta (Θ)
- Best-case, average-case, and worst-case analysis
- Analyzing loops and recursive algorithms
- Common growth rates: constant, logarithmic, linear, and exponential

## 3. Arrays

- One-dimensional and multidimensional arrays
- Traversal, insertion, deletion, and updating
- Prefix sums and difference arrays
- Two-pointer technique
- Sliding-window technique
- Array rotation and rearrangement
- Maximum subarray sum: Kadane’s algorithm

## 4. Strings

- String representation and basic operations
- Character frequency counting
- Palindromes and anagrams
- Substrings and subsequences
- String matching basics
- Two-pointer and sliding-window problems on strings

## 5. Searching Algorithms

- Linear search
- Binary search and its prerequisites
- First and last occurrence
- Lower and upper bounds
- Searching rotated sorted arrays
- Binary search on the answer

## 6. Sorting Algorithms

- Bubble sort
- Selection sort
- Insertion sort
- Merge sort
- Quick sort
- Heap sort
- Counting sort and radix sort
- Stability, in-place sorting, and complexity comparisons

## 7. Singly Linked List (SLL)

- Node structure: data and next pointer
- Creating and traversing an SLL
- Insertion at the beginning, end, and a given position
- Deletion at the beginning, end, and a given position
- Searching and updating nodes
- Reversing an SLL
- Finding the middle node
- Finding the nth node from the end
- Detecting and removing a cycle
- Merging two sorted linked lists

## 8. Doubly Linked List (DLL)

- Node structure: previous pointer, data, and next pointer
- Creating and traversing a DLL in both directions
- Insertion at the beginning, end, and a given position
- Deleting a node and updating adjacent links
- Searching and updating nodes
- Reversing a DLL
- Advantages, limitations, and memory overhead
- Applications in deques and LRU caches

## 9. Circular Linked List (CLL)

- Circular singly linked lists
- Circular doubly linked lists
- Head and tail links in circular lists
- Traversal and termination conditions
- Insertion at the beginning, end, and a given position
- Deletion at the beginning, end, and a given position
- Handling empty and single-node lists
- Splitting a circular linked list
- Applications: round-robin scheduling and the Josephus problem

## 10. Stacks

- Last In, First Out (LIFO) principle
- Array and linked-list implementations
- Push, pop, peek, and empty checks
- Balanced parentheses
- Infix, postfix, and prefix expressions
- Expression conversion and evaluation
- Monotonic stacks and next greater element

## 11. Queues and Deques

- First In, First Out (FIFO) principle
- Array and linked-list implementations
- Enqueue, dequeue, and front operations
- Circular queues
- Double-ended queues (deques)
- Implementing a queue using stacks
- Monotonic deques and sliding-window maximum

## 12. Hashing

- Hash functions and hash tables
- Hash maps and hash sets
- Collision handling: chaining and open addressing
- Load factor and resizing
- Frequency counting and duplicate detection
- Pair-sum and subarray-sum problems

## 13. Recursion and Backtracking

- Base cases and recursive calls
- Call stack and recursion trees
- Recursive array and string problems
- Generating subsets, permutations, and combinations
- Backtracking decisions and undoing changes
- N-Queens, maze paths, and Sudoku
- Pruning unnecessary search branches

## 14. Trees and Binary Search Trees

- Tree terminology and representations
- Binary trees
- Preorder, inorder, and postorder traversals
- Level-order traversal
- Height, depth, and diameter
- Balanced and symmetric tree checks
- Lowest common ancestor
- Binary search tree (BST) search, insertion, and deletion
- Validating a BST
- Introduction to AVL and red-black trees

## 15. Heaps and Priority Queues

- Min-heaps and max-heaps
- Array representation of a binary heap
- Insertion, extraction, and heapify
- Building a heap
- Priority queue operations
- Top-K elements and kth largest/smallest problems
- Merging sorted sequences

## 16. Graphs

- Directed, undirected, weighted, and unweighted graphs
- Adjacency lists and adjacency matrices
- Breadth-first search (BFS)
- Depth-first search (DFS)
- Connected components
- Cycle detection and bipartite graph checks
- Topological sorting
- Shortest paths: BFS, Dijkstra, Bellman–Ford, and Floyd–Warshall
- Minimum spanning trees: Prim’s and Kruskal’s algorithms
- Introduction to strongly connected components
