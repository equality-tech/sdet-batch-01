# Linux Basics for SDETs — Course Contents

## 1. Basic System Commands

| Command | Purpose |
| --- | --- |
| `pwd` | Show the current directory |
| `whoami` | Show the current user |
| `hostname` | Show the machine name |
| `uname -a` | Show system information |
| `date` | Show the current date and time |
| `clear` | Clear the terminal display |
| `man <command>` | Open a command's manual |

## 2. Files and Directories

| Command | Purpose |
| --- | --- |
| `ls` | List files and directories |
| `ls -la` | Include hidden files and permission details |
| `cd <directory>` | Change directory |
| `cd ..` | Move to the parent directory |
| `cd ~` | Go to your home directory |
| `mkdir <directory>` | Create a directory |
| `touch <file>` | Create an empty file or update its timestamp |
| `cp <source> <destination>` | Copy a file |
| `cp -r <source> <destination>` | Copy a directory |
| `mv <source> <destination>` | Move or rename a file or directory |
| `rm -i <file>` | Delete a file after confirmation |
| `rmdir <directory>` | Remove an empty directory |

## 3. Reading Files and Logs

| Command | Purpose |
| --- | --- |
| `cat <file>` | Display file contents |
| `less <file>` | Browse a file; press q to exit |
| `head -n 20 <file>` | Display the first 20 lines |
| `tail -n 50 <file>` | Display the last 50 lines |
| `tail -f <log-file>` | Follow live log updates; press Ctrl+C to stop |
| `wc -l <file>` | Count lines by newline characters |

## 4. Searching Files and Text

| Command | Purpose |
| --- | --- |
| `find . -name '*.log'` | Find log files below the current directory |
| `grep 'ERROR' app.log` | Find matching log lines |
| `grep -i 'error' app.log` | Search without case sensitivity |
| `grep -n 'ERROR' app.log` | Include line numbers |
| `grep -C 3 'ERROR' app.log` | Include surrounding lines |
| `grep -r 'BASE_URL' config/` | Search inside a directory recursively |

## 5. File Permissions

- Read, write, and execute permissions
- Owner, group, and others
- Recognizing permission-denied errors

| Command | Purpose |
| --- | --- |
| `ls -l <file>` | View permissions and ownership |
| `chmod u+x <file>` | Give the owner execute permission |
| `chmod 644 <file>` | Give the owner read/write and everyone else read access |
| `sudo chown <user>:<group> <file>` | Change ownership when authorized |

## 6. Processes and Disk Usage

| Command | Purpose |
| --- | --- |
| `ps -ef` | List processes |
| `pgrep -af '<pattern>'` | Find processes by command line |
| `top` | Monitor processes; press q to exit |
| `kill -TERM <pid>` | Request termination of an identified process |
| `free -h` | Show memory usage |
| `df -h` | Show filesystem space usage |
| `du -sh <directory>` | Show a directory's total disk usage |

## 7. Networking and Application Checks

| Command | Purpose |
| --- | --- |
| `ip addr` | Show network addresses |
| `ping -c 4 <host>` | Check ICMP reachability where allowed |
| `getent hosts <host>` | Look up a host address |
| `ss -lnt` | List listening TCP ports |
| `curl <url>` | Send a GET request and display the response body |
| `curl -i <url>` | Include response headers |
| `curl -I <url>` | Send a HEAD request |
| `curl -o response.json <url>` | Save a response to a file |


## 8. Remote Access and File Transfer

| Command | Purpose |
| --- | --- |
| `ssh <user>@<host>` | Connect to a remote machine |
| `ssh -p <port> <user>@<host>` | Connect using a custom SSH port |
| `scp <file> <user>@<host>:<directory>/` | Upload a file |
| `scp <user>@<host>:<file> ./` | Download a file |
| `exit` | Close the remote shell session |

## 9. Archives and Basic File Editing

| Command | Purpose |
| --- | --- |
| `tar -czf logs.tar.gz logs/` | Compress a log directory |
| `tar -tzf logs.tar.gz` | List archive contents |
| `tar -xzf logs.tar.gz` | Extract the archive into the current directory |
| `unzip reports.zip` | Extract a ZIP archive when unzip is installed |
| `nano <file>` | Open a file in nano when installed |

**nano shortcuts:** Ctrl+O to save, Enter to confirm the filename, and Ctrl+X to exit.

## 10. Basic Pipes and Output Redirection

| Command / Syntax | Purpose |
| --- | --- |
| `command > output.log` | Save stdout, replacing existing file content |
| `command >> output.log` | Append stdout to a file |
| `command 2> errors.log` | Save stderr to a file |
| `grep 'ERROR' app.log \| wc -l` | Count matching error lines |
| `command \| tee output.log` | Display and save stdout |

## 11. SDET Practice

- Find an application's log file and inspect recent errors.
- Search configuration files for an environment URL.
- Check whether an application port is listening.
- Check an endpoint's response using curl.
- Identify a running process and inspect resource usage.
- Download logs from a remote machine and compress them.
- Identify a file permission issue.
