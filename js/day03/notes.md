var: named storage for data. It can hold different types of values such as numbers, strings, arrays, objects, etc. Variables are declared using the var keyword in JavaScript.

int a=10;
String str="hello world";
float f=10.5;

syntax: var variableName = value;

data type: what type of data a variable can hold. Common data types in JavaScript include:

primitives:

- Number: represents numeric values (e.g., 10, 3.14)    
- String: represents sequences of characters (e.g., "hello", 'world')
- Boolean: represents true or false values (e.g., true, false)      

- null: represents the intentional absence of any object value (e.g., null)
- undefined: represents a variable that has been declared but has not yet been assigned a value (e.g., undefined)

- bigint: represents whole numbers larger than 2^53 - 1 (e.g., 9007199254740991n)

- symbol: represents a unique and immutable value that can be used as an identifier for object properties (e.g., Symbol('description'))


non primitives: arrays objects, functions, etc.
