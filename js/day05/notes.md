condtional statements:
if, else if, else, switch, case, default

if: it gets executed when the condition is true
syntax:
if(condition){
    //statements
}

else: it gets executed when the condition is false
syntax:     
else{
    //statements
}

else if: this will be executed, when the condition is false, and act like a 1 more condition to check

else if(condition){
    //statements
}

notes:
1. in a program, we can have any number of if conditions
2. else block is not a mandatory
